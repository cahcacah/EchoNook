# EchoNook

Handles secure video conferencing for small teams with end-to-end encryption and screen sharing.

EchoNook is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Handles secure video conferencing for
- small teams with end-to-end encryption
- and screen sharing

- Handles secure video conferencing for

- and screen sharing

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/EchoNook.git`
2. `cd EchoNook`
3. Install in editable mode: `pip install -e .`

## Configuration

EchoNook is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
